# Tutorials

Each tutorial takes you from nothing to a working result, one step at a time. Take them in order.

- [Your first record](first-record.md) builds a record from a schema, commits it to a store and reads it back.
- [A scenario on a branch](scenario.md) branches that record, overrides one value and materialises the child.
- [Solve a record with PyPSA](pypsa.md) solves a record with the PyPSA tool and commits the results.
