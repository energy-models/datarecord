    Schema¶

    Schema ¶

    Bases: _Declared

    One record's schema.

    Attributes:

    Name Type Description
    id UUID | None

    A standalone record's id, which its manifest.json carries beside the declarations and Workspace.write mints; None on a tree's schema, and then left out of a dump.
    version int

    Bumped by any change to the declarations. A reader meeting a version it was not written for should refuse rather than guess.
    dimensions dict[str, Dimension]

    Every declared axis, keyed by dim name.
    attributes dict[str, AttributeSpec]

    Attribute -> spec, flat and record-wide. One attribute is one spec and one attributes/<attr>.parquet, so a dtype cannot differ per type.
    properties dict[str, dict[str, PropertySpec]]

    Subject dim or group -> property name -> spec: the columns of dims/{dim}.parquet or groups/{group}.parquet that describe its labels. A name is unique within its subject only, addressed as subject.name. A property of a dim in partial that takes its labels from a dim listing its labels categorizes its subject.
    groups dict[str, Group]

    Group name -> which tuples over several dims exist.
    partial frozenset[str] | None

    Which dims a layer may patch value by value. None for a record with no layers, since nothing overrides anything. A dim outside it is one a layer owns entirely once it touches it.
    meta dict[str, Any]

    A framework's own top-level data - network attributes, CRS, free-form metadata. Stored and never interpreted, since none of it describes the dimensioned data.
    Notes
    • the schema
    • partial
    • versioning

    broadcast_dims property ¶

    broadcast_dims: tuple[str, ...]

    The coordinates a NULL broadcasts over: every declared dim and every group column.

    A NULL here means "every value of this dim", which the fold expands against the axis; a NULL struct means every tuple of the resolved group.

    What the varies/broadcast structs have a field per, and what expand_dims joins.

    Notes
    • the broadcast rule
    • groups

    group_columns property ¶

    group_columns: tuple[str, ...]

    Every group, each carried in a row as one struct column named for it.

    Notes
    • groups

    partial_dims property ¶

    partial_dims: tuple[str, ...]

    The fold key's coordinates, in declaration order.

    The dims and groups a layer may patch per value (partial). The fold's key is one fixed tuple over all attributes, so it carries every axis any layer may patch by value or by row, not only those some currently declared attribute varies over. An attribute not owned per one of them writes NULL there, the "NULL means all values" rule - which also lets a schema declare an axis before any attribute uses it.

    Notes
    • partial
    • one fold for every axis
    • the owner map

    long_columns property ¶

    long_columns: tuple[str, ...]

    The long schema's full column set.

    The map's column set, which is uniform across attributes because the map is one relation over all of them. An individual file carries only its own attribute's columns (long_columns_for), and union_by_name supplies NULL for the rest when the fold unions them here.

    Notes
    • the long schema

    input_key property ¶

    input_key: tuple[str, ...]

    Inputs-map key columns, compared NULL-safely when folding.

    partial_dims, plus attribute: a layer may patch one value along a partial dim or group without restating every other's.

    A coordinate an attribute's own file does not carry reads as NULL, which is what makes the key one fixed tuple over attributes whose columns differ.

    Notes
    • connections

    def coordinates_of(self, attribute: str) -> tuple[str, ...]:

    A group in `dims` is carried as one struct column named for it
    (`group_type`), so `dims={"connection", "snapshot"}` gives

    def duck_type(self, spec: Dimension | AttributeSpec | PropertySpec) -> DuckDBPyType:
    """Return the DuckDB type of a declared dim, attribute or property.

    A dim that lists its labels has the `ENUM` of them. A property that
    takes its labels from a dim has the type of that dim.

    -----
    - [dtypes](https://energy-models.github.io/datarecord/design/schema/#dtypes)

    return DUCK_TYPES[cast("str", spec.dtype)]

    def check_group_columns(
    self,
    groups: Iterable[str],
    rel: DuckDBPyRelation,
    *,
    carrier: str,
) -> None:
    """Reject each of `groups` carried other than as one struct column of exactly its key, whole or NULL.

    A carrier without a group's column passes.

    Parameters
    ----------
    carrier
        What carries the columns, named in the message.

    Raises
    ------
    ValueError
        On a key coordinate as a column of its own, a group column not a
        struct of exactly the key, naming the struct to pass instead, or a
        struct with some fields NULL and not all.

    Notes
    -----
    - [groups](https://energy-models.github.io/datarecord/design/schema/#groups)
    - [the broadcast rule](https://energy-models.github.io/datarecord/design/record/#the-broadcast-rule)
    """
    types = dict(zip(rel.columns, rel.types, strict=True))
    for group in groups:
        key = self.group_key(group)
        flat = [c for c in key if c in types]
        dtype = types.get(group)
        fields = (
            key
            if dtype is None
            else [name for name, _ in dtype.children]
            if dtype.id == "struct"
            else None
        )
        if flat or fields is None or set(fields) != set(key):
            carried = f"{flat} flat" if flat else f"{group!r} as {dtype}"
            msg = (
                f"{carrier} carries {carried}; pass {group!r} as one struct "
                f"column with a field per key coordinate, {list(key)} (https://energy-models.github.io/datarecord/design/schema/#groups)"
            )
            raise ValueError(msg)
        if dtype is None:
            continue
        some = " OR ".join(
            f"{fn.struct_extract(col(group), lit(c))} IS NULL" for c in key
        )
        partly = sql(f"{col(group)} IS NOT NULL AND ({some})")
        if rel.filter(partly).limit(1).fetchone() is not None:
            msg = (
                f"{carrier} carries a {group!r} with some fields NULL; a "
                f"group value is a whole tuple, or NULL for every tuple (https://energy-models.github.io/datarecord/design/record/#the-broadcast-rule)"
            )
            raise ValueError(msg)

    def require_listed(
    self, subject: str, data: Mapping[str, Iterable[Any]], what: str
) -> None:
    """Refuse a label its dim does not list.

    `data` maps column names to values. A name is checked where it is
    `subject` and `subject` lists its labels, or where it is a property of
    `subject` that takes its labels from a dim listing them. Other names
    and NULL values are skipped.

    Raises
    ------
    ValueError
        Naming `what`, the column, the unlisted labels and the labels the
        dim lists.

    Notes
    -----
    - [dtypes](https://energy-models.github.io/datarecord/design/schema/#dtypes)
    """
    specs = self.properties.get(subject, {})
    for name, values in data.items():
        if name in specs:
            listed = self._listed(specs[name])
        elif name == subject and subject in self.dimensions:
            listed = self._listed(self.dimensions[subject])
        else:
            continue
        if listed is None:
            continue
        unknown = sorted({str(v) for v in values if v is not None} - {*listed})
        if unknown:
            msg = (
                f"{what} gives {name!r} labels {unknown}, which its dim "
                f"does not list; that dim lists {list(listed)}"
            )
            raise ValueError(msg)

    def default_for(self, name: str, **categories: str) -> Any:
    """The default of attribute or `subject.name` property `name` for a label of `categories`.

    `categories` are keyed by each categorizing property's own name. The

    `default`; a category left out matches none.

    Raises
    ------
    KeyError

    Notes
    -----
    - [AttributeSpec](https://energy-models.github.io/datarecord/design/schema/#attributespec)

    return spec.default

    def resolve(self, name: str) -> AttributeSpec | tuple[str, PropertySpec]:
    """What `name` addresses: an attribute, or a property as `subject.name`.

    Read off the name alone: a plain name is never a property.

    Returns
    -------
    AttributeSpec or tuple of str and PropertySpec
        The attribute's spec, or a property's subject and spec.

    Raises
    ------
    KeyError
        If `name` addresses nothing; for a plain name some subject's
        property is called, naming each dotted form.

    Notes
    -----
    - [properties](https://energy-models.github.io/datarecord/design/schema/#properties)
    """
    subject, dot, prop = name.partition(".")
    if dot:
        spec = self.properties.get(subject, {}).get(prop)
        if spec is None:
            msg = f"the schema declares no property {name!r}"
            raise KeyError(msg)
        return subject, spec
    attribute = self.attributes.get(name)
    if attribute is not None:
        return attribute
    dotted = sorted(
        f"`{s}.{name}`" for s, specs in self.properties.items() if name in specs
    )
    hint = f"; did you mean {' or '.join(dotted)}" if dotted else ""
    msg = f"the schema declares no attribute {name!r}{hint}"
    raise KeyError(msg)

    def field_over(self, group: str, dim: str) -> str | None:
    """The one field of `group` over `dim`, if any.

    ------
    ValueError
        If several fields of `group` are over `dim`.

        raise ValueError(msg)
    return fields[0] if fields else None

    owned_per ¶

    owned_per(attribute: str) -> frozenset[str]

    def require_takes(
    self,
    rel: DuckDBPyRelation,
    what: str,
    subject: str | None = None,
    attribute: str | None = None,
) -> DuckDBPyRelation:
    """Check that each column of `rel` has a type that fits its declaration, and return `rel`, with its all-NULL columns cast to their declared types.

    A column type fits where `takes` says so. A column
    that fails this but holds only NULLs passes and is cast to its declared
    type, because dataframe libraries guess the type of an empty or
    all-None column. Only such columns have their rows read. `subject` and
    `attribute` are as in `declared`.

    Raises
    ------
    ValueError
        Naming `what`, and for each refused column its type, its
        declared name and its dtype.

    Notes
    -----
    - [dtypes](https://energy-models.github.io/datarecord/design/schema/#dtypes)
    - [set](https://energy-models.github.io/datarecord/design/working-record/#set)
    """
    wrong = []
    nulls: dict[str, DuckDBPyType] = {}
    for c, given in zip(rel.columns, rel.types, strict=True):
        found = self.declared(c, subject, attribute)
        if found is None or takes(found[1], given):
            continue
        if rel.filter(col(c).isnotnull()).limit(1).fetchone() is None:
            nulls[c] = found[1]
            continue
        name, _, shown = found
        wrong.append(
            f"column {c!r} has type {given}, which does not fit {name!r} "
            f"of dtype {shown}"
        )
    if wrong:
        msg = f"{what}: {'; '.join(wrong)}"
        raise ValueError(msg)
    if not nulls:
        return rel
    return rel.project(
        *(
            col(c).cast(nulls[c]).alias(c) if c in nulls else col(c)
            for c in rel.columns
        )
    )

    def compatible_with(self, other: Schema) -> list[str]:
    """Why layers written under `other` would not read under `self`.

    Empty when the change is compatible: old layers stay readable and only
    `version` moves. The compatible changes are those where NULL already
    means what the new schema needs it to mean, so the broadcast rule absorbs
    them without touching a row.

    Returns
    -------
    list of str
        One reason per incompatibility, empty if there are none.

    Notes
    -----
    - [the broadcast rule](https://energy-models.github.io/datarecord/design/record/#the-broadcast-rule)
    - [versioning](https://energy-models.github.io/datarecord/design/schema/#versioning)
    """
    problems = []

    for dim, was in other.dimensions.items():
        now = self.dimensions.get(dim)
        if now is None:
            problems.append(f"dim {dim!r} removed")
            continue
        if _typed_as(now) != _typed_as(was):
            problems.append(f"dim {dim!r} {_typed_as(was)} -> {_typed_as(now)}")

    for attr, was_spec in other.attributes.items():
        now_spec = self.attributes.get(attr)
        if now_spec is None:
            problems.append(f"attribute {attr!r} removed")
            continue
        if now_spec.dtype != was_spec.dtype:
            problems.append(
                f"attribute {attr!r} dtype {was_spec.dtype} -> {now_spec.dtype}"
            )
        narrowed = was_spec.dims - now_spec.dims
        if narrowed:
            problems.append(
                f"attribute {attr!r} no longer varies over {sorted(narrowed)}; "
                f"rows setting those dims have no valid reading"
            )

    for dim, specs in other.properties.items():
        for name, was_prop in specs.items():
            now_prop = self.properties.get(dim, {}).get(name)
            if now_prop is None:
                problems.append(f"property {name!r} of {dim!r} removed")
            elif _typed_as(now_prop) != _typed_as(was_prop):
                problems.append(
                    f"property {name!r} of {dim!r} {_typed_as(was_prop)} "
                    f"-> {_typed_as(now_prop)}"
                )

    if other.partial is not None and self.partial is not None:
        lost = other.partial - self.partial
        if lost:
            problems.append(
                f"{sorted(lost)} no longer `partial`; a layer that patched one "
                f"value along such an axis is now a partial override of an axis "
                f"owned whole"
            )
    return problems
